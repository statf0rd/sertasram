# Ручная проверка перед релизом

Что нельзя проверить автотестами: живые устройства, разрешения ОС и звонок
между разными компьютерами. Нужны два компьютера (лучше один Windows и один Mac),
наушники, адрес сервера с токеном и сборки из последнего
[релиза](https://github.com/statf0rd/stars/releases). Напротив каждого пункта
ставьте «ок» или описание проблемы.

Если что-то сломалось, приложите лог:

- Windows (установщик): `%LOCALAPPDATA%\stars\stars.log`, прошлый запуск - `stars.log.prev`;
- Windows (zip): текст в окне консоли после закрытия приложения;
- macOS: `~/Library/Logs/stars.log`.

## 1. Установка

- [ ] **Windows, установщик.** Запустить `stars-windows-x64-setup.exe`. Права
      администратора не спрашиваются, лицензия читается по-русски, в меню «Пуск»
      появился ярлык stars, приложение открывается без чёрного окна консоли.
- [ ] **Windows, обновление.** Поставить установщик ещё раз поверх. Приложение
      запускается, сохранённые адрес, комната и имя на месте.
- [ ] **Windows, удаление.** «Параметры» - «Приложения» - stars - «Удалить».
      Папка `%LOCALAPPDATA%\Programs\stars` и ярлык исчезли.
- [ ] **Windows, zip.** Распаковать `stars-windows-x64.zip`, запустить
      `Запустить stars.bat` - приложение открывается.
- [ ] **macOS, dmg.** Открыть dmg своей архитектуры (Apple Silicon - arm64, Intel -
      x64), перетащить stars в «Программы», выполнить
      `xattr -cr /Applications/stars.app`, открыть. В «Об этой программе» /
      свойствах файла версия совпадает с релизом.
- [ ] **macOS, обновление.** Заменить `/Applications/stars.app` новой версией.
      Разрешение на запись экрана не слетело.

## 2. Вход и голос

- [ ] Вставить адрес сервера с токеном в поле «Сервер», ввести одинаковую комнату
      и разные имена на двух компьютерах, «Войти в комнату». У обоих второй
      участник появился со статусом «на связи».
- [ ] При первом входе система спросила доступ к микрофону, после разрешения
      голос слышен в обе стороны без заметной задержки и эха (в наушниках).
- [ ] «Микрофон вкл» → «Микрофон выкл»: собеседник перестаёт слышать, обратно -
      снова слышит.
- [ ] Неверный токен или выключенный сервер: понятная ошибка, приложение не
      зависает.

## 3. Камера

- [ ] «Камера»: система спрашивает разрешение (macOS), появляется своё
      зеркальное превью, у собеседника - ваша камера.
- [ ] Выбор камеры в списке (если камер несколько, например встроенная и USB или
      телефон): картинка переключается на ходу, у собеседника тоже.
- [ ] «Выключить камеру»: превью и плитка у собеседника пропадают.
- [ ] Перезапуск приложения: выбранная камера запомнилась.
- [ ] Без камеры или с запрещённым доступом: сообщение «камера не найдена
      (проверьте подключение и разрешение)», кнопка возвращается в «Камера».

## 4. Демонстрация экрана и пресеты

- [ ] «Демонстрация»: на macOS система спрашивает запись экрана, у собеседника
      экран идёт крупно, камеры - колонкой справа.
- [ ] Движение на экране (видео, прокрутка) у собеседника плавное, текст читается.
- [ ] Переключить пресеты во время показа: Экономный 720p30, Плавный 720p60,
      Сбалансированный 1080p30, Чёткий 1440p15. Показ перезапускается с новым
      качеством, звонок не рвётся. Выбранный пресет запоминается после перезапуска.
- [ ] Остановить показ: у собеседника плитка экрана пропадает, камеры
      раскладываются сеткой.
- [ ] Показывают оба одновременно: у каждого виден экран другого.

## 5. Звук демонстрации

- [ ] Включить музыку или видео со звуком и «Звук демонстрации»: собеседник
      слышит системный звук отдельно от голоса, в стерео (проверка L/R из
      `scripts/measure/make-test-media.sh`).
- [ ] Говорить поверх музыки: голос не глушит музыку, музыка не обрезается
      шумоподавлением.
- [ ] На Windows остальные звуки системы не приглушаются, когда начинается звонок.
- [ ] Выключить «Звук демонстрации»: системный звук у собеседника пропадает,
      голос остаётся.

## 6. Несколько участников и выход

- [ ] Три-четыре участника в одной комнате: все видят и слышат всех, плитки не
      накладываются.
- [ ] «Выйти» у одного: у остальных он исчезает из списка вместе с плитками,
      звонок у остальных продолжается.
- [ ] Повторный вход в ту же комнату без перезапуска приложения работает.
- [ ] Закрыть окно во время звонка с камерой и демонстрацией: приложение
      закрывается полностью (нет процесса java/javaw в диспетчере задач или
      мониторинге системы).

## 7. Разные сети

- [ ] Один компьютер на домашнем Wi-Fi, другой на мобильном интернете (раздача с
      телефона). Соединение устанавливается («на связи»), а не висит на
      «соединение…» или «ошибка» - значит TURN работает.

## 8. Статистика для замеров

- [ ] Запуск с `SERTAS_STATS=on` (как - в [measurements.md](measurements.md)):
      в `~/.sertas/stats/` появился CSV, в нём строки `in`/`out` для `mic`,
      `screen`, `camera` с ненулевыми FPS и битрейтом.
